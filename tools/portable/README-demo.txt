DODGING CAT - WINDOWS X64 PORTABLE DEMO

1. Extract the entire ZIP to a writable folder.
2. Double-click Run.cmd and wait for first preparation to finish.
3. Open Run.cmd again for later launches. No installed Java, JDK, Maven,
   7-Zip or Internet is required.

Keep the whole extracted folder together. Do not launch from inside a ZIP
viewer. The game shares art/audio with the included source directory.

F11: fullscreen/windowed. F10: FPS display.
F9: developer money; pressing F9 again resets this portable profile.
Save data: DodgingCat/data/profile.json beside this copy.

Open-source.cmd opens the full Java/Maven source and test files for review.
This compact demo edition does not include the compiler or Build.cmd.
Use the development checkout or the larger buildable portable edition to edit
and rebuild offline. The source can be built on a machine with JDK 25/Maven.

If preparation fails, use Troubleshoot.cmd and inspect game-debug.log.
For folders with Vietnamese characters, the scripts make an ASCII runtime
cache under LocalAppData or Public/DodgingCatPortableRuntime. Save data still
stays beside the original portable folder. An ASCII folder path avoids the
extra cache. Windows x64 only.

The final report and slides are separate and must fit the LMS file limit
together with this demo archive. See the external build-report.json for size.
